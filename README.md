# SingleTrack volunteer rego platform

Planning for a new volunteer registration platform to replace iVolunteer.

- `docs/volunteer-rego-scope.html`: draft scope (v0.4, 12 November 2026) with ten platform ideas, pros and cons, a scorecard and a recommended starting point. Open it in a browser.
- `docs/phase-one-prototype.html`: clickable example of the Phase 1 volunteer sign-up and team roster, with made-up demo data.
